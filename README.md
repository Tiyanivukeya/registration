Java Registration, Login and Messaging System

Project Overview
This is a Java program that allows users to register for their own accounts and log back into the system using their registered username and password. After successfully logging in, users can also send messages to other users.

The project demonstrates basic Java programming concepts such as user registration, login authentication, user input, data validation, and messaging functionality.

Features
* User registration
* User login and authentication
* Username and password validation
* Ability to send messages
* Simple command-line interface
* Error handling for incorrect login details

How It Works
1. A new user creates an account by registering a username and password.
2. The system stores the user's account information.
3. The user can log back into the system using their registered credentials.
4. Once logged in, the user can access the messaging functionality.
5. Users can send messages through the system.
6. The system provides feedback when actions are completed successfully or when incorrect information is entered.

Technologies Used
* Java
* Java Scanner
* Object-Oriented Programming
* Git
* GitHub

Purpose
The purpose of this project is to practise Java programming by building a simple user authentication and messaging system. It demonstrates how registration, login, and communication features can be combined into one application.
